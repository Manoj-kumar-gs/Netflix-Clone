# 🎬 Netflix Clone UI

A simple Netflix landing page clone built using only **HTML** and **CSS**. This project is intended for learning and practice purposes, mimicking the visual layout of Netflix’s homepage.

---

## 🛠️ Tech Stack

- HTML  
- CSS

---

## 🚀 How to Run

1. Clone the repository  
2. Open `index.html` in your browser  
No build tools or installation needed.

---

## 📝 Notes

- This UI is not responsive for smaller screens.  
- Designed primarily for desktop view only.  
- Created as a static UI clone – no functional features like sign-in or media playback included.
